# CoveyKeep

CoveyKeep is a web-first platform built around persistent groups rather than one-off events: every gathering keeps its photos, its people, and its story permanently, and can be turned into a printed keepsake book written from what everyone contributed. Canonical project documentation lives in the Hub docs root at `D:\projects\Project-Hub\covey-keep\`. Note: the name is settled as **CoveyKeep** (one word, deliberately) pending final counsel sign-off; the `covey-keep` slug in repo names, hosts, and paths is filesystem convention, not branding, and does not change with the name. User-visible brand strings live in `frontend/src/brand.ts` and `backend/app/brand.py` and nowhere else.
