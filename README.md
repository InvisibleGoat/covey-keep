# Covey Keep

Covey Keep is a web-first platform built around persistent groups rather than one-off events: every gathering keeps its photos, its people, and its story permanently, and can be turned into a printed keepsake book written from what everyone contributed. Canonical project documentation lives in the Hub docs root at `D:\projects\Project-Hub\covey-keep\`. Note: the working name "Covey Keep" is **not cleared** — trademark search and attorney review are pending, and a rename is an accepted possibility.
